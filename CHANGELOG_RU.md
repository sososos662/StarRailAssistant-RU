# Изменения StarRailAssistant-RU

Внутренняя версия приложения остаётся `2.25.0-beta.1`. Идентификатор ревизии
форка хранится отдельно в `FORK_VERSION`, чтобы не выдавать форк за новый upstream-релиз.

## 2.25.0-beta.1-ru.20261028.1 — подготовлено к публикации

- Исправлена навигация финала SSS, когда OCR оригинального размера выдаёт
  «下一» вместо «下一步»: дополнительное чтение той же области в 2× масштабе
  требует полного слова и прежних независимых доказательств страницы.
- Добавлен серый fallback того же ROI для чтения финальных HP. Противоречивый,
  низкоуверенный или недопустимый RGB-результат им не перекрывается; две свежие
  проверки HP и прежние ограничения сохранены.
- Добавлен обезличенный записанный результат и публичные регрессии финала.
- Явно инициализирован список OCR-токенов в анализаторе населения для blocking lint;
  пороги и правила распознавания не изменены.
- Подготовлены описание форка, атрибуция, безопасный CI, инструкции сборки,
  защиты приватных данных и процедура создания настоящего GitHub fork.
- Сверены описания обычных CurrencyWars и Plus с официальной базой и кодом:
  исправлены подпись Химеко, число партий и описание расширения; исторические
  сведения v2.24.1 отделены от текущей базы. Этапы экономики и сам Plus не
  выдаются за новые разработки форка; штатные JSON сохранены без изменений.
- Унаследованные публикации в upstream R2/MirrorChyan/PyPI не активны в форке.
- С разрешения владельца сохранён вариант «Химэко Нова (Европа)» с его игровым
  кодом; правила стратегии не менялись. Остальные личные копии не публикуются.
- Ссылки метаданных указывают на `sososos662/StarRailAssistant-RU`. Git сохраняет
  исходные байты файлов без автоматической замены переводов строк, чтобы
  Source ZIP, GitHub-архив и контрольный манифест совпадали.
- Причина конкретного partial_store в новом логе установлена: видимое имя
  Первопроходца не совпадало с настроенным. Не добавлены выдуманные алиасы,
  неизвестные слоты не объявлены пустыми; настройка пользователя не переписана.

## Локальная ревизия 27.10.2026

- UI-001: адресное чтение U0187 для «Это не» / `'Sequence Read Archive'`,
  устранение несовпадения LF/CRLF в поиске перевода.
- DIAG-001: сохранение участвовавшего кадра и OCR неполной витрины в прежних квотах.
- PERF-001: векторизация геометрии/цветов магазина и устранение больших
  индексных массивов поиска, без пропуска проверок страниц.
- PERF-002: консервативный отсев невозможных проекций задней линии с fallback
  на исходный полный поиск, без изменения порогов и golden-диагностики.
- DIAG-002: исключительные тайминги, ограниченные записи и снимок реальных
  провайдеров трёх OCR-моделей при инициализации.
- Переносимый DirectML OCR для проверенной комбинации API/native, CPU и
  fallback при недоступном адаптере; никакой установки системного драйвера.

## Локальные изменения 26–27.10.2026

- Русский desktop/WebUI/CLI, подписи схем расширений, UTF-8 pipe/stdout/stderr,
  Unicode-шрифты и исправления переполнения элементов интерфейса.
- Исправления подтверждения состава, пустых слотов, покупок, разметки,
  поддержек, переходов и штатного терминального завершения CurrencyWarsPlus.
- Оптимизация отдельных вычислений и расстановки с сохранением проверок
  неизвестных, TTL 60 секунд, транзакционных подтверждений и остановки.

Это краткое описание форка, не замена [оригинальному ChangeLog2.0.md](ChangeLog2.0.md).
PERF-003 остаётся исследованием: общая безопасность удаления повторных открытий
магазина не доказана. Результаты тестов и ограничения — [docs/TESTING.ru.md](docs/TESTING.ru.md).
