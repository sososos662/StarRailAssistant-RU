# Проверки и границы доказанного

Тесты выполняются без запуска игры, без `task run` / `extension run` и без
реального игрового ввода. Подставляются границы снимка/OCR/ввода, а не внутренние
решения алгоритма. Записанные OCR-ответы не выдаются за новый живой OCR-прогон.

## Python

```powershell
python scripts/check_offline.py --output ../checks-1 tests
python -m flake8 SRACore extensions tasks tests scripts main.py --count --select=E9,F63,F7,F82 --show-source --statistics
```

`--output` должен быть новым каталогом. APPDATA/LOCALAPPDATA/TEMP/TMP тестового
процесса изолируются, сторонние pytest-плагины автоматически не загружаются.
Результаты — `pytest.log` и JUnit XML. Для короткого прогона укажите пути тестов:

```powershell
python scripts/check_offline.py --output ../checks-terminal tests/test_currency_wars_terminal_recorded235133.py tests/test_currency_wars_terminal_exit.py
```

Opt-in performance-тест пропускается по умолчанию: он не должен превращаться
в нестабильную проверку скорости конкретного CPU в обычном CI.

## WebUI / .NET

В `SRAFrontend/srafrontend-webui`:

```text
pnpm install --frozen-lockfile
pnpm exec oxlint .
pnpm exec eslint .
pnpm type-check
pnpm test
pnpm build
```

Первые две проверки не используют `--fix`, чтобы CI не менял исходники.
Из корня: `dotnet build` для desktop и server `.csproj` с SDK 10.
После изменений bindings/localization желательно дополнительно проверить
desktop-вёрстку и три языка: успешная компиляция не доказывает отсутствие обрезки текста.

## Обезличенные fixtures

`tests/fixtures/terminal_recorded_235133/summary.png` содержит только центральную
панель результата без UID, имени и пользовательских путей. `ocr.json` содержит
реальные ответы для конкретных хешей пикселей. Тест использует публичный
`handle_game_over()` и реальный template matching, но записанный OCR и fake-ввод.
Ни сам бот, ни игра при таком тесте не запускаются.

## Чего тесты не доказывают

Успех всех партий, всех стратегий и всех GPU; отсутствие санкций аккаунта;
ускорение всей партии на коэффициент OCR-бенчмарка; автоматический полный выход
из нового игрового прогона после последнего патча. Реальный журнал показывает
победный кадр, но задача была остановлена пользователем до подтверждения выхода.
Перед заявлением о полной автоматизации нужна отдельная приёмка с разрешения владельца.
