# Диагностика

## Неполная витрина / partial_store

Проверьте точное имя Первопроходца в **Расширения → Валютные войны Plus → Настройки**.
Оно должно совпадать с текущим аккаунтом, включая латиницу и регистр. Старое имя
после смены аккаунта не подходит. Неизвестные имена не объявляются пустыми слотами
и не получают автоматически права на покупку.

Штатный same-frame путь сохраняет исходный кадр, ROI и оба OCR-разбора в пределах
квот. Старый резервный `operator.ocr()` не возвращает участвовавший кадр —
поздний снимок за него не выдаётся. Отсутствие файла также может означать квоту
или ошибку записи; сохранённая диагностика содержит объясняющие статусы.

## Финал не закрывается

Один «Следующий шаг» не доказывает конец партии: похожие кнопки используются
и при старте. Нужны заголовок, идентичность страницы, точное действие и две
свежие согласованные страницы. В этой ревизии добавлен same-frame 2× OCR для
случая «下一» вместо полного «下一步», без снижения порогов.

## DirectML / CPU

Смотрите `OCR_PROVIDERS` в начальном host/backend-журнале. Строка записывается
при создании моделей, иногда раньше отдельного журнала расширения. Она показывает
список реальных провайдеров сессий при инициализации, не долю GPU-узлов или загрузку GPU.
Для принудительного CPU: `rapidocr/config.yaml` → `use_dml: false` → полный перезапуск.
Все версии и ограничения: [GPU_OCR.ru.md](../GPU_OCR.ru.md).

## Тайминги

`CW_TIMING` содержит исключительные длительности. Старый `phase_seconds` / inclusive
таймер к ним **не прибавляется**. Категория `recovery` — только её собственное время,
а полная операция восстановления определяется соответствующим `scope`.
`process_s` — время всего процесса, не одного потока и не GPU. Время `wait` не
считается безусловно устранимым простоем.

## Язык и масштаб

Русским является интерфейс помощника. Игра — **简体中文, 1920×1080**, масштаб Windows
и параметры окна должны соответствовать проверенной конфигурации. `UnicodeEncodeError`
не следует обходить заменой символов в игровых именах. Полностью распакуйте архив,
не переносите только EXE без ресурсов и библиотек.

## Что приложить к Issue

Ревизию из `FORK_VERSION`, внутреннюю версию, Windows/GPU, режим CPU/DirectML,
язык/разрешение игры, краткие шаги, ожидаемый и фактический результат. Только
обезличенный фрагмент журнала/кадра: [SECURITY.md](../SECURITY.md).
