# StarRailAssistant-RU 2.25.0-beta.1-ru.20261028.1

Неофициальный русскоязычный форк **Shasnow/StarRailAssistant v2.25.0-beta.1**,
база `863509072bf2011b4d5a3e3d71072b6cd269637e`. Не официальный релиз
Shasnow/HoYoverse и не текущая upstream-ветка. Лицензия AGPL-3.0-or-later.

## В составе

- Русский desktop, WebUI, CLI и подписи настроек расширений; UTF-8 и кириллица.
- Исправления и консервативные оптимизации CurrencyWarsPlus, подтверждение покупок,
  состава, разметки и переходов без отключения защитных проверок.
- Переносимый DirectML OCR с CPU-вариантом; API ONNX Runtime 1.27.0 / native 1.24.4.
- Ограниченная диагностика неполной витрины, тайминги и провайдеры моделей.
- Исправление финала, где OCR читал «下一» вместо «下一步», и чтения финальных HP.

## Проверки и ограничения

В итоговом полном прогоне **2209 Python-тестов прошли, 1 opt-in пропущен**;
18 адресных проверок финала прошли. Набор локализации: 2009 PASS, включая две
новые регрессии описаний; WebUI: lint/type-check/build PASS, 106 тестов PASS.
Проверки offline, без реального игрового ввода. Новое полное прохождение после
последнего патча не заявляется. Замер 2,73× относится к одному OCR-набору,
не к всей партии. Повторы неполного магазина PERF-003 остаются исследованием.

Русским является помощник; игре нужны **简体中文 и 1920×1080**. Точное имя
Первопроходца в настройках должно совпадать с именем на игровом аккаунте.
Автоматизация может нарушать правила игры; гарантий безопасности аккаунта нет.

## Установка

Полностью распакуйте Windows x64 runtime ZIP в отдельную папку, сверьте `.sha256`,
запустите `SRA.exe`, выберите Русский и подтвердите перезапуск. Не запускайте
программу из ZIP и не копируйте один EXE. `Source.zip` / GitHub Download ZIP —
исходники, а не готовая программа. Настройки в AppData не входят в поставку.

Штатный upstream-updater может заменить форк официальной версией. До отдельного
канала обновляйте вручную только из Releases этого форка. Подробности —
README_RU, FORK, BUILDING и SECURITY в исходниках. Логи и кадры очищайте от
UID/ников/путей/секретов до публикации в Issues.

Перед внешней публикацией дополните этот шаблон реальными именами assets и их
SHA256 из конкретной проверенной поставки. Не копируйте контрольные суммы старого архива.
