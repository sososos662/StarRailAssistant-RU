# StarRailAssistant-RU

**Русскоязычный неофициальный форк [Shasnow/StarRailAssistant](https://github.com/Shasnow/StarRailAssistant)
на базе `v2.25.0-beta.1`.**

[Русский](README.ru.md) · [English](README.en.md) · [中文](README.zh.md)

**[Скачать готовую сборку](https://github.com/sososos662/StarRailAssistant-RU/releases)** ·
**[Инструкция по запуску](README_RU.md)** ·
**[Сообщить об ошибке](https://github.com/sososos662/StarRailAssistant-RU/issues)**

Помощник автоматизирует действия в **Honkai: Star Rail** с помощью распознавания
экрана. Этот форк предназначен прежде всего для русскоязычных пользователей.
Это не только перевод интерфейса: здесь также исправлены и оптимизированы
отдельные сценарии уже существующего CurrencyWarsPlus.

## Что добавлено и улучшено в форке

- **Русский интерфейс:** desktop, WebUI, CLI и описания настроек. Исправлены
  UTF-8-обмен между процессами, отображение кириллицы и отдельные подписи.
- **Исправления «Валютных войн Plus»:** обработка неизвестных/пустых мест,
  проверки покупок и состава, восстановление и финальная страница SSS.
  Для финала исправлены неполное OCR кнопки и чтение HP — без отключения
  подтверждений, двух свежих кадров и остановки.
- **Оптимизация вычислений:** ускорены отдельные проверки магазина, страниц и
  задней линии; убрана часть доказанно повторной работы, сохранены пороги и проверки.
- **DirectML OCR:** переносимое распознавание через GPU с CPU-вариантом и
  откатом при ошибке инициализации адаптера. [Состав и ограничения](GPU_OCR.ru.md).
- **Диагностика:** ограниченные кадры и OCR неполной витрины, раздельные тайминги
  и фактические провайдеры модельных сессий.
- **«Химэко Нова (Европа)»:** сохранён предоставленный владельцем вариант
  `himeko_global_europe_20261026.json` с его игровым кодом. Правила покупок,
  расстановки и экономики в этом JSON не менялись.

**Что уже было в оригинале:** сам CurrencyWarsPlus, этапы состава и экономики,
две штатные стратегии, конечная экономика 3-7 и рекомендованная экипировка.
Форк не приписывает себе создание этих механизмов. Два штатных JSON сохранены
байт в байт. Подробнее: [FORK.md](FORK.md), [CHANGELOG_RU.md](CHANGELOG_RU.md).

## Быстрый запуск

1. Скачайте **готовый Windows x64 ZIP** из [Releases этого форка](https://github.com/sososos662/StarRailAssistant-RU/releases).
   `Code → Download ZIP` и `Source.zip` — исходники, не готовая программа.
2. Сверьте SHA256, полностью распакуйте архив в отдельную папку и запустите `SRA.exe`.
   Отдельные Python и .NET готовой сборке не нужны. Антивирус отключать не требуется.
3. Выберите **Настройки → Отображение → Язык → Русский**, подтвердите перезапуск.
4. Для Plus откройте **Расширения → Валютные войны Plus → Настройки**: укажите
   точное имя Первопроходца текущего аккаунта, стратегию и параметры запуска.

**Русским является помощник. Игра должна использовать упрощённый китайский
язык — 简体中文 — и разрешение 1920×1080.**

В поставке три JSON-стратегии: две штатные и вариант Европы. У Химеко с уровня 7
для дальнейшего обычного опыта требуется выставленная **Химеко 2★**, а не весь
состав 2★; её цель закупки остаётся 3★. [Подробные настройки и экономика](extensions/cw_plus/CONFIGURATION.ru.md).

## Важно знать

- Это не официальный релиз Shasnow или HoYoverse. Автоматизация может нарушать
  правила игры; гарантий безопасности аккаунта, победы или прохождения нет.
- Новое полное игровое прохождение после последнего исправления финала не заявляется.
  Успешные offline-тесты не заменяют проверку в живой игре.
- Замер около 2,73× относится к конкретному OCR-набору, **не к скорости всей партии**.
- Штатный upstream-updater может заменить форк оригинальной версией. Пока
  обновляйте эту сборку вручную из Releases данного репозитория.
- Логи и кадры могут содержать UID, имя и секреты. Не загружайте их без очистки:
  [SECURITY.md](SECURITY.md).
